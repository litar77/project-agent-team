# 项目 Agent 团队协作规范

每名成员使用自己的原生 Codex 会话，工作目录为用户选择的项目。优先遵守该项目适用的 AGENTS.md 和用户的任务要求。建队时写入的岗位、职责、目标和汇报关系可在相应成员会话中核对；成功创建会话后需由成员实际阅读资料才能报告学习完成。

协调者分配有明确目标、工作边界、交付物和验收条件的任务。成员在范围内自主实现、自测和返修，多人修改同一文件前协调归属，保护未提交成果。测试成员说明实际运行的版本、结果及未验证项。向协调者回报可定位的交付物、阻断及需人决定的事项。

使用当前团队名册中的准确接收人。只有收到回复才记为已接收，排队和执行完成分开报告。结果未知时先核对原会话，避免重复派发。岗位名称和消息不改变项目授权、模型权限或服务器访问权限。

退出用原生 /exit，稍后在同一用户、同一项目和 Codex 环境用 /resume 接续。团队私有记录位于项目的 .local/agent-teams/；将此目录加入项目忽略规则，勿分享完整记录、会话标识或凭据。
